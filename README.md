# FinAssist connectors

Каталог коннекторов банков для приложения FinAssist: подписанные пакеты и два канала
обновлений. Это статический репозиторий — GitHub Pages отдаёт файлы как есть, никакого
сервера и базы нет.

## Раскладка

```
stable/catalog.json      что видят все пользователи
beta/catalog.json        что видят включившие бету
packages/<id>/<ver>.zip  сами пакеты (неизменяемые)
sources/<id>/            исходники пакета: manifest.json, скрипт, иконка
keys/connectors-public.pem  публичный ключ (приватный здесь не хранится)
sign.py                  сборка, подпись, продвижение
config.json              базовый адрес каталога
```

## Формат пакета

ZIP, детерминированный (фиксированное время и порядок файлов):

```
manifest.json   паспорт: id, version, apiVersion, minAppVersion, hosts, permissions, title, entry, icon
adapter.js      скрипт (имя из manifest.entry)
icon.png        иконка (имя из manifest.icon)
```

Подпись — SHA256withRSA по байтам ZIP. Приложение проверяет отпечаток и подпись до разбора
архива, поэтому пересборка обязана давать те же байты.

## Выпуск версии

Приватный ключ держите вне репозитория и передавайте только путём:

```bash
export CONNECTORS_KEY=~/keys/connectors-private.pem

# 1. собрать и положить в бету
python sign.py build --src sources/vtb --version 12 --channels beta --changelog "что изменилось"

# 2. проверить на телефоне: Коннекторы -> канал Бета -> Проверить обновления

# 3. продвинуть ту же запись в стабильный канал
python sign.py promote --id vtb --version 12

# 4. проверить подпись и отпечаток
python sign.py verify --id vtb --version 12
```

`build` можно сразу публиковать в оба канала: `--channels beta,stable`.

## Отзыв версии

Поставить `"withdrawn": true` в записи каталога (в обоих каналах) и закоммитить.
Приложение перестанет запускать эту версию и откатится на предыдущую или встроенную.

## Правила

- приватный ключ никогда не коммитится и не публикуется;
- версии пакетов неизменяемы: исправление — новая версия, а не перезапись файла;
- каталог кешируется GitHub Pages ~10 минут, приложение запрашивает его с меткой времени.
